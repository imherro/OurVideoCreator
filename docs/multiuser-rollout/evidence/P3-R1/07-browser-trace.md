## 浏览器与服务端闭环

1. 管理员从登录页进入 `/admin`；用户行显示“签发重置”，`/members` 显示“移出团队”和“移除作品权限”。重置原始 token 只在签发响应/页面中出现一次。
2. 管理员创建一次性邀请。Edge 使用邀请完成注册，页面先显示“等待加入团队”，证明注册不会自动获得团队或作品权限。
3. 管理员创建 `P3R1 浏览器作品`，把成员加入默认团队并只授予该作品 `viewer`。Edge 刷新后实际进入作品概览，页面明确显示 `viewer` 只读提示与禁用保存按钮。
4. 隔离库中再创建 `P3R1 成员团队`，让该成员成为 owner。Edge 刷新后团队选择器同时出现两个团队；切到默认团队可见被授权作品，切到 owner 空团队只显示“创建第一部作品”。再次刷新后选择器与空团队状态一致，不带出另一团队的作品。
5. 通过同一后端的受认证管理入口签发并消费密码重置。保持旧 Cookie 的 Edge 刷新后立即回到登录页；使用新密码登录成功，证明旧会话失效而新凭据有效。
6. 通过受认证管理入口撤销默认团队的作品权限并移出团队。Edge 刷新后选择器只剩 `P3R1 成员团队`，默认团队和 `P3R1 浏览器作品` 均不可见，无跨团队残留。
