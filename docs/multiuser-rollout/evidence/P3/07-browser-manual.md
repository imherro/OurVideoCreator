# P3 浏览器手工验证记录

- 环境：独立 Uvicorn 端口 7893、独立 PostgreSQL 测试数据库、独立浏览器上下文。
- 管理员：成功登录；`/admin` 展示用户、团队、邀请管理；`/members` 展示团队/作品成员并掩码手机号。
- 普通成员：注册登录后在无团队时展示“等待加入团队”。
- 加入团队：无作品权限时展示“尚未加入作品”，没有泄漏其他作品。
- 多团队：选择器同时展示成员团队和 owner 团队，切换后状态随当前团队变化。
- 空 owner 团队：展示“创建第一部作品”，普通 member 不展示对应管理动作。
- 清理：浏览器临时标签关闭、临时服务停止、专用测试数据库删除；未触碰端口 7868 的用户服务。

这是 UI 可用性补充记录；权限结论以服务端 HTTP/数据库/SSE 自动化测试为准。
