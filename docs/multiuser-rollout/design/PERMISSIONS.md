# 身份与对象协作权限矩阵

## 角色

- 平台：`platform_admin` / `user`。
- Workspace：`owner` / `member`。
- Production：`manager` / `editor` / `viewer`。
- Workspace owner 对本 Workspace 的 Production 具有管理能力，但跨租户访问必须走显式、审计的后台入口。

## 强制约束

1. 注册邀请只建立账号，不自动入组；手机号不能成为授权依据。
2. manager 不能把非 Workspace 成员直接加入 Production。
3. 普通成员不得列举全站用户或完整手机号。
4. 成员移除后撤销租约和编辑权，成果保留并标记待重新分配。
5. 保留最后一个有效 platform_admin 和 Workspace owner。
6. viewer 只读但可以评论；不能生成、删除、取得编辑租约或调用隐藏写 API。
7. 所有列表、详情、历史、回收站、素材、任务、事件、批量入口和导出都执行相同租户/作品边界。
8. 管理员跨租户内容访问必须使用显式后台入口并产生审计，不能在普通查询中设置万能 bypass。
9. `POST /api/projects` 当前会同时创建 Production 和首集，因此迁移期间必须与“创建 Production”同权（WO；PA 仅后台显式审计），不得作为 manager 越权兼容入口；manager 创建分集只能使用已有 Production 下的 Episode 命令。

## P3 落地状态与后续边界

P3 已移除共享密码/session，所有现有 API 使用个人数据库 session、CSRF 与 Workspace/Production 服务端 ACL；列表、详情、嵌套 ID、历史、回收站、素材/Range、任务和 SSE 均按当前成员关系复核。平台管理员不在普通业务查询中拥有跨租户万能旁路；管理动作使用 `/api/admin/*` 并写审计。

P3-R1 把会减少有效管理员或成员关系的写操作放入同一个数据库事务级身份不变量锁：团队 owner 降级/移除、用户停用、作品授权与团队撤权不会留下零 owner、零平台管理员或孤立作品授权。读端同时要求有效团队成员关系；仅有遗留 `production_members` 行不能获得列表、详情、文件或 SSE 权限。

P3-R2 对每个认证限流 key 使用稳定的事务级 advisory lock，连首次桶尚未建行时也串行判定；密码恢复统一以 user 行为锁根，再锁并复核 token。并发签发会线性替换旧凭证，消费同时撤销同用户其他未消费凭证，避免双 token 与反向锁序。

限流窗口和重置有效期使用取得锁后的当前时间，避免排队期间过期仍获准消费。`tests/test_p3_r2_interleavings.py` 通过回环 HTTP 和 `pg_stat_activity` 等待关系验证首次/过期/清空桶，以及双重签发和签发/消费两种先后顺序；不降低密码哈希成本，不引入新基础设施。

P3 仍处于内部试用边界。对象 assignee、接管、细粒度 revision 与 lease 在 P5 落地；在此之前 editor 可使用已有对象 API，但不能使用旧整份 `PUT /api/projects/{pid}`、删除/恢复资源或操作他人任务。Provider 凭证版本化和安全模型目录在 P4，多 Worker 执行前二次授权与额度在 P6。

## P5 当前实现补充（未签发外部通过）

- 服务端身份共享屏障与 P3 成员变更排他屏障协调；获取对象行锁后重新核验有效会话、团队成员、作品角色、负责人、revision 和 assignment_epoch。不同镜头保持独立行锁。
- manager/owner 修改他人正文、恢复内容、采纳结果也须明确接管；管理权限只赋予分配及确认/退回能力。原著批量删除核全部章节，不能作为 manager 覆盖他人内容的旁路。
- 图结构对允许创建/修改结构的 editor 开放，但边/节点删除或依赖改变继续检查受影响对象权限；没有把 graph 负责人作为全局创作锁。导演台 capture 同时核 stage 负责人、stage/graph 版本和本集真实图片素材。
- viewer 只能查看和评论，不能取得编辑租约、生成或采纳。对象与章节/剧本的历史、评论、候选详情同样执行作品 scope。
- 用户停用、团队/作品撤权、降为 viewer 后对象内容及素材保留，旧代际和租约失效；重新分配 A→B→A 不会复活旧页面权限。
- 旧整份项目 PUT 不向任何角色提供协作写入口。纯设置仅允许 manager/owner 小 PATCH；Provider/Key/模型仍由平台独占。
- 任务结果先登记候选；恢复查询已有远端任务不意味着可以写回。显式采纳检查当前负责人/版本/代际和冻结引用；无远端句柄的重排也须当前对象权限与原目标版本。P6 执行租约及额度未实现，不用上述验证冒充 P6。
