## 冻结业务流程

制片人分工 → 编剧提交剧本 → 制片人验收 → 资产师制作并提交共享资产 → 制片人验收 → 抽卡师拆镜、生成并选定素材 → 交付剪辑包 → 剪辑师线下剪辑、回传样片 → 制片人按秒帧批注 → 剪辑师回复并上传新版 → 制片人批准明确样片版本。

- 无抽卡结果/素材分集审批。只审核剧本、共享资产、剪辑样片。
- 每作品多选角色，同角色可多人。一集一位抽卡师，可负责多集；作品默认编剧、资产师、剪辑师，分集可明确覆盖编剧/剪辑师。
- 章节按范围分工，资产按业务卡片批量分工；不引入组织树、工作组或通用任务平台。
- 作品制片人不授予 Workspace owner 或平台管理员。所有写操作在服务端按角色与实际分工核验，不能用 manager 绕过。
- 默认分工只决定新内容；现有内容转交须显式确认。整集转交不带走剧本或共享资产；原子更新、撤销旧租约、保留历史。撤权及恢复历史不能复活旧写权限。
- 已批准剧本允许拆镜准备；正式镜头生成要求剧本和实际引用资产已批准。资产自身生成允许在资产审批前。分集制作可流水并行，不等全片。
- 分镜 AI 新资产只能成为资产待办/候选，抽卡师不得越权写入共享资产。所有生成必须明确采纳。
- 交付清单固定选定视频、顺序、剧本、对白及必要音频；版本不可被后续修改替换。
- 样片原文件保留，独立版本、按时间/帧定位与批注回复。变帧率/不兼容编码需要规范审片副本并验证定位。批注绑定原视频版本，不自动搬到新版秒数。
- 日常对象分配隐藏，制片人高级异常入口保留；审核/历史/冲突处理留在业务页。成员均可查看作品，剪辑师不需制作对象编辑权。
