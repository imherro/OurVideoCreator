# 协作版：动作参考与显式视频模式

本批将冻结上游 `13939a82` 的动作参考需求适配到 PostgreSQL 协作对象、平台模型目录和单 Worker；没有复制单机整份项目 PUT、免审核或自动覆盖行为。上传音色样本、状态独立音色属于后续需求，不在本批完成范围。

## 使用

- 新建作品的网页表单默认选择“多模态参考”；当前制作集设置可修改默认值，镜头可覆盖。旧文档没有字段时保持 `legacy`，不批量改写旧项目。为了兼容旧 API 调用方，创建接口省略 `video_reference_mode` 仍为 legacy；网页显式传入 multimodal。旧项目手工新增镜头默认显式 multimodal，历史镜头保持原行为。
- 视频工作区和高级画布中的镜头视频节点可上传/绑定一段完整 MP4，设置动作角色、摄像机模式和补充说明。绑定保存在镜头的 `motionReference`；引用的是本作品正常素材。解绑不删除素材，不自动加入剪辑，不裁剪/变速，不改计划镜头时长。
- 多模态会提交完整图片参考：镜头已有图、尾帧作为普通构图参考、输入图片以及已锁定角色/场景/道具主参考。去重编号，不截断；超过平台发布限制直接报错。只有一张图也保持参考协议，不降级为首帧。
- 严格首帧要求恰好一张图；严格首尾帧另需受支持的尾帧。不能混入动作视频、固定对白音频或额外视觉绑定；切换模式/模型保留绑定，提示用户调整，不偷偷删除。
- “预览最终提交与参考清单（不生成）”调用只读 `/api/projects/{id}/video-spec`，展示实际编译 prompt、参考编号、计划/提交/参考时长与冻结参数。可以在生成运行中查看；不会创建任务、衍生素材或修改对象。预览包含尚未保存的本镜设置，正式生成仍须正常保存、校验负责人和版本。

## 管理员发布能力

沿用现有后台模型定义 JSON，无新后台页面、依赖或数据库迁移；不会自动更改已发布模型。

- 必须显式发布 `multimodal_reference: true`，动作视频另需 `video_reference: true`，图片另需 `image_reference: true` 和 `max_references`。固定对白继续使用已发布的 `audio_reference` 和 `generate_audio` 规则。仅音频提交另需 `audio_only_reference: true`，默认不开启。
- 模型须发布 `duration`、`ratio` 允许规则和有效默认值，实际冻结参数必须落在这些规则内。`max_video_duration` 和 `max_reference_duration` 发布时按私有上游型号生成，管理员可收紧，不能超过已接通协议上限。
- 接通：HC 的 doubao/dreamina-seedance-2.0/2.5；Ark 的 doubao-seedance-2-0/2-5 型号族；RunningHub 的 bytedance/seedance-2.5-token、seedance-2.5-global-token。未知别名不发布能力，不猜测或换模型。2.0 上限 9 图/15 秒，2.5 上限 30 图/30 秒；平台可进一步收紧。
- HC/Ark 动作视频使用现有 `public_base_url` 短期签名素材地址；预览仅验证地址，不创建签名密钥或链接。RunningHub 使用现有二进制上传。真实公网可达性、鉴权和生成质量未验证，不因此授权部署或付费。

## 媒体与协作边界

- MP4 必须真实含 H.264/H.265 视频流，≤200 MB，时长 2 秒至发布上限，24–60 FPS，边长 300–6000，宽高比 0.4–2.5，总像素 407696–8295044，并可完整解码。预览的解码缓存仅在内存且有数量上限。
- 任务冻结原文件 SHA256、探测信息、引用和编译版本，不保存临时上传 URL/签名。首次执行有原声的视频使用 FFmpeg stream-copy 去声，保留源文件；派生素材按正常权限登记并复用。它不是回收/恢复平台，不自动清理历史衍生素材。
- 参考/镜头模式变化通过对象命令加锁，提高对应视频及图下游的 generation_revision，已有输出标 stale。其他负责人的正文、分配和租约不被覆盖；并发旧版本保存正常冲突，旧任务仍为候选，需显式采纳。改变本集默认模式仅直接影响未覆盖默认值的视频及其下游。
- 批量运行中的待生成图片以 durable job ID 解析，不再使用该节点旧图片。由于提示词编号已冻结，该上游任务须恰好生成一张图片；零张/多张明确失败，用户选定素材后重提，不截断或重新编号。预览中的待生成项属于计划引用，不声称已经生成。
- 已有远端任务 ID 走原查询路径，不重新上传或创建第二个供应商任务。无真实付费调用；供应商请求体测试使用 Mock，媒体测试使用本地 FFmpeg，业务集成使用真实隔离 PostgreSQL。

测试入口：`tests/test_motion_references.py`、`tests/motion_reference.test.mjs`；组件隔离页 `tests/motion_reference_browser.html`（复用 `node tests/image_settings_browser.mjs` 启动无 API 代理的 Vite 测试服务）。它验证组件交互，不是业务登录后的完整浏览器 E2E。
