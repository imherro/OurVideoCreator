# 协作版图片生成设置

适配上游 `9b55ccf`，不导入单机模型管理或本地推理部署。分镜列表、宫格和高级画布使用同一个 `ImageGenerationSettings`，编辑同一 image node 的 `model_id`、`parameters` 和显式 `imageSettings`，经原对象保存、revision 和草稿流程提交。查看/折叠/切换入口不写业务数据，设置变化保留旧素材并标记结果待更新。切换模型保留参数，不兼容时显示校验错误；“恢复项目默认”是显式重置。

`POST /api/projects/{pid}/image-spec` 是本地只读参数预览，作品 viewer 即可访问；仍校验登录、CSRF、作品范围及平台模型可用性。支持预览尚未保存的项目画幅/视频分辨率，并包含旧节点的顶层参数校验。不排任务、不调用模型目录/生成接口，不暴露私有工作流、凭证或供应商地址。预览不是执行授权：提交仍须保存成功，并通过对象负责人、版本、参考素材和能力检查；实际画幅读取服务端已保存状态。

## 平台约束下的尺寸与种子

- 默认采用项目画幅推荐尺寸（SYNC-07）；原 `resolution` 不被当作新的显式自定义意图。仅 `imageSettings.sizeMode=custom|video` 开启覆盖。
- 云端本轮仅开放跟随项目画幅；规格不是供应商实际输出像素保证。RunningHub 同时发送像素与质量档，保留其 `2k` 含义。
- Maestro 外部 API，以及包含宽高占位符的 ComfyUI 私有模板，只有同时发布 resolution 字符串规则后才提供自定义/视频像素选项；所有值继续满足管理员枚举及长度限制。自定义宽高为256–4096、8的倍数、比例误差不超过2%。不自动扩大已发布模型规则。
- 固定种子仅在已接通适配器（Maestro或含seed占位符的ComfyUI）且发布seed整数规则时开放。不支持的固定种子明确拒绝，包含直接传入parameters的情况。
- `-1` 表示随机。预览不抽取随机数；创建任务时从平台规则允许的非负整数中选择并冻结，规则没有合法值时预览/提交均报错。幂等重试使用原模型、配置和原种子，不因管理员更新而重抽。
- 未发布像素或种子控制时明确显示未受控，不注入未发布字段、不声称已控制实际输出。

新图片任务的只读 `input.image_spec` 展示安全的冻结规格，其parameters与job_private冻结参数相同，Worker继续从私有快照读取。客户端伪造同名字段不影响冻结或幂等判定。任务详情将冻结值与原请求区分，防止把原请求的旧默认尺寸误认为实际发送尺寸。

不回填历史任务或素材；没有新表、迁移、依赖、后台配置或本地模型启动器。生成结果仍为候选，需要明确采纳。单次/批量进入同一解析器，批量入口不再重复注入图片ratio别名。

验证入口：`tests/test_image_settings.py`（真实PG及模拟协议）、`tests/test_upstream_image_aspect.py`、`tests/image_settings.test.mjs`；`node tests/image_settings_browser.mjs` 是无业务API代理的隔离组件页，仅证明前端交互，不冒充完整登录端到端或真实供应商验证。
